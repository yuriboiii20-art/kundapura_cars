# 🚗 KUNDAPURA_CARS — Kundapura's Certified Used Car Marketplace

A modern, high-trust, light-themed web application inspired by **Spinny**, tailored exclusively for **Kundapura & Coastal Karnataka** used car buyers. Built with **React 18**, **TypeScript**, **Tailwind CSS**, and **21st.dev style** component design aesthetics.

---

## ✨ Key Features & Architecture

### 1. 🏙️ Kundapura Exclusive Focus (Buy Only)
- **100% Buy-Focused**: No selling distractions — pure, certified inventory for car buyers.
- **Kundapura Locked Location**: Location chip fixed to Kundapura with direct access to our 5 certified experience yards (Kundapura NH 66 Hub, Shastri Circle Hub, Kodi Beach Road Center, Udupi Coastal Express, and Mangalore Highway Yard).
- **Free Doorstep Test Drives**: Book test drives directly to your home or office anywhere across Kundapura & Udupi district.

### 2. 🛡️ The "Kundapura Assured" 4-Pillar Promise
- **200-Point Comprehensive Inspection**: Rigorous forensic evaluation of Engine, Transmission, Suspension, Brakes, High-Strength Body Structure, AC, and Electricals with verified 0 accidental history.
- **1-Year Comprehensive Warranty**: Complete coverage on engine & gearbox + 24x7 Roadside Assistance in Karnataka.
- **5-Day 100% Money-Back Guarantee**: Drive up to 300 km / 5 days with zero-risk full refund.
- **Free Karnataka RTO Transfer**: Direct transfer to Kundapura RTO (KA-20) and all Karnataka RTOs handled by in-house RTO desk.

### 3. 🔍 Smart Discovery & Multi-Facet Filters (21st.dev Styling)
- **Budget Slider & Quick Presets**: Filter under ₹7L, ₹7L–₹12L, ₹12L–₹18L, and above ₹18L.
- **Body Style Selector**: SUV, Sedan, Hatchback, EV, Luxury, and MUV.
- **Fuel & Transmission**: Petrol, Diesel, Electric, Hybrid, Automatic (DCT, DSG, CVT, AT), and Manual.
- **Brand / Make**: Hyundai, Mahindra, Tata, Honda, Maruti Suzuki, Toyota, Volkswagen, Skoda, BMW.
- **Live Search**: Instant keyword search matching make, model, variant, tags, and Kundapura RTO codes.

### 4. 🔬 Deep Car Inspection Modal & 360° Studio View
- **Multi-Angle Gallery & 360° Simulator**: High-resolution exterior and interior photos with 360° rotation simulation.
- **Interactive 200-Point Inspection Viewer**: Detailed checklists and scores across Engine, Steering, Paint, Cabin, and AC & Tyres.
- **Full Technical Specifications Matrix**: Engine displacement, max power, ARAI certified mileage, seating, airbags, boot capacity, and ground clearance.
- **Dynamic EMI & Loan Planner**: Live sliders for down payment, loan tenure, and interest rate with principal vs. interest breakdown.

### 5. ⚡ Test Drive & ₹999 Reservation Flow
- **Kundapura Hub or Home Test Drive**: Select your preferred Kundapura area or experience hub, date, and time slot.
- **Celebratory Confetti & Instant Voucher**: Instant booking confirmation voucher with Hub manager helpline.
- **₹999 Refundable 48-Hour Reservation**: Hold your dream car exclusively with 100% money-back guarantee.

### 6. ⚖️ Side-by-Side Car Comparison
- Select up to 3 vehicles to compare specs, pricing, inspection ratings, and features side-by-side.

### 7. 📱 100% Mobile Responsive
- Responsive top navbar, mobile search, slide-out wishlist drawer, sticky mobile filter sheet, and touch-optimized car cards.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
git clone https://github.com/yuriboiii20-art/kundapura_cars.git
cd kundapura_cars
npm install
```

### Run Locally (Dev Server)
```bash
npm run dev
```
Open `http://localhost:5173/` in your browser.

### Production Build
```bash
npm run build
npm run preview
```
